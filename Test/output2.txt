=== Problem 1: Basic Function Template ===
[add]
add(10, 20) = 30  [T deduced: int]
add(3.5, 1.2) = 4.7  [T deduced: double]
add<int>(10, 20) = 30  [explicit: T = int]
add<double>(10, 20) = 30  [explicit: T = double]
[maxValue]
maxValue(10, 20) = 20  [T deduced: int]
maxValue(3.5, 1.2) = 3.5  [T deduced: double]
=== Problem 2: Template Argument Deduction ===
[1] Implicit Deduction — same type
add(3, 7) = 10  [T=int]
add(1.5, 2.3) = 3.8  [T=double]
[2] Explicit Template Argument
add(3, 7) = 10  [T=double]
[3] Mixed Types — Explicit 로 해결
add(3, 1.5) = 4.5  [T=double]
=== Problem 3: Multiple Template Parameters ===
[Part 1] Single Type Parameter (limitation)
[NOTE] add<T>(8, 3.5) → Compile Error: T cannot be both int and double
[Part 2] Two Type Parameters (T, U)
add(8, 3.5) = 11.5  [T=int, U=double]
add(3.5, 8) = 11.5  [T=double, U=int]
[Part 3] auto Return Type Deduction
subtract(8, 3.5) = 4.5  [auto → double]
subtract(3.5, 8) = -4.5  [auto → double]
